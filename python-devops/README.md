# Python DevOps Environment

Python tools for automation, infrastructure, and DevOps.

## Included

- Python 3.10, 3.11, 3.12, 3.13
- `pip` - Package manager
- `poetry` - Dependency management
- `pyenv` - Python version management
- `ansible` - Automation
- `kubernetes` client

## Usage

```bash
flox activate

# Install dependencies
poetry install

# Run Python scripts
python script.py
```
