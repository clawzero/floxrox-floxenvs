# Python DevOps Flox Environment

Python tools for automation and DevOps.

## Packages

- Python 3.12 (full)
- pip, poetry, pyenv
- Ansible
- Docker client

## Usage

```bash
flox activate

# Python
python3 script.py

# Poetry
poetry install
poetry run pytest

# Ansible
ansible-playbook site.yml

# Docker
docker ps
```
